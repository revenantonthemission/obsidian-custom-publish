# Functional Design Questions: Résumé Certifications

The requirements settle the facts and the layout, and the existing certification entry already has an issuer line and a link row. One wording choice is yours.

## Question 1
What should the AWS certificate's verification link say? It is shown under the certificate, like other evidence links, and is marked as external.

A. `자격 검증`
B. `AWS 자격 검증`
C. `자격 증명 확인`
X. Other (please specify)

[Answer]: X. `인증 확인 링크` (the maintainer first chose A, then corrected it to this wording)
