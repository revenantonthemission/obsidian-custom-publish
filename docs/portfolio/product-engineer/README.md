# Product engineer portfolio

The product engineer portfolio lives at `/portfolio/product-engineer`. The existing data engineer / AI portfolio remains at `/portfolio`.

`site/src/lib/profile/portfolio-roles.ts` defines role navigation, editorial introductions, project focus labels, and the curated project selection. Both visible content and metadata use that selection. New roles should be registered here and given an explicit selection; the static role route is generated from the registry.

The product engineer edition currently includes only DocSuri. Its introduction focuses on search and reading workflows, implementation priorities, team collaboration, and service operation. DocSuri is shortened to the incident, user-priority queues, contracts, team responsibilities, bounded measurements, and remaining quality limitations.

Project facts, source links, contact details, and fact IDs are reused verbatim from the existing approved production profile. The role introduction and focus labels are editorial framing authorized by the request to add a product engineer portfolio. They do not represent a new human fact review or add claims about adoption, customer research, revenue, or conversion. The existing profile approval receipt and résumé PDF are unchanged.
