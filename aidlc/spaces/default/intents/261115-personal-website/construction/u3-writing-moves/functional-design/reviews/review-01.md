### Summary

The design covers the acceptance criteria of US4.1, US5.1, US5.2 and US7.1 honestly — the `N/A`, `Deferred` and reverse rows are defensible and the three sensors pass — but the redirect table's writer is inert under the installed Astro version: `site/src/pages/_redirects.json.ts` is skipped by the router, so the table never reaches the build output and every old address would answer 404 instead of 301. The second blocking gap is the table's freshness trigger, which does not cover the table appearing after the server starts, the case the upstream contract still lists as an open question blocking U3's release.
