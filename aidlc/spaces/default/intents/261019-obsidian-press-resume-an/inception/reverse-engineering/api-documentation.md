# API Documentation

## Runtime REST APIs

The deployed site has no runtime application server, REST API, database, or authenticated endpoint. All application-owned responses are static CloudFront/S3 objects.

## Public Static HTTP Surface

### Homepage

- **Method**: GET
- **Path**: `/`
- **Purpose**: Render the `passion-project` content, professional-profile links, today's posts, and knowledge hubs.
- **Request**: No body or query contract.
- **Response**: Static HTML with shared CSS and optional hydrated islands.

### Post

- **Method**: GET
- **Path**: `/posts/{slug}`
- **Purpose**: Render one Vault note.
- **Response**: Static HTML with post metadata, related content, backlinks, navigation, and interactive enhancements.

### Hub

- **Method**: GET
- **Path**: `/hubs/{slug}`
- **Purpose**: Render a hub and its child navigation.
- **Response**: Static HTML.

### Tag Index and Tag Detail

- **Method**: GET
- **Paths**: `/tags`, `/tags/{tag}`
- **Purpose**: Browse content grouped by sanitized tag.
- **Response**: Static HTML.

### Graph

- **Method**: GET
- **Path**: `/graph`
- **Purpose**: Render the full knowledge graph.
- **Response**: Static HTML plus a hydrated Preact graph.

### RSS

- **Method**: GET
- **Path**: `/rss.xml`
- **Purpose**: Syndicate non-hub posts.
- **Response**: Generated RSS XML.

### Generated JSON Contracts

- **Method**: GET
- **Paths**: `/search-index.json`, `/graph.json`, `/previews.json`, `/nav-tree.json`
- **Purpose**: Supply runtime search, graph, preview, and navigation islands.
- **Response**: Static JSON generated by the Rust preprocessor.

### Generated Assets

- **Method**: GET
- **Path**: `/assets/{filename}`
- **Purpose**: Serve copied images and rendered diagrams.
- **Response**: Static binary or SVG asset.

## Rust CLI API

### Command

`obsidian-press [--stamp-published] <vault> <output>`

- **`vault`**: Input Obsidian directory.
- **`output`**: Generated content directory.
- **`--stamp-published`**: Mutates Vault frontmatter by writing publication dates before preprocessing.
- **Returns**: Process success or an `anyhow` error.

## Rust Internal APIs

### Scanning

- `scan_vault(vault_path) -> Result<VaultIndex>`: Recursively scan non-hidden Markdown outside `Drafts`.
- `stamp_published_dates(vault_path) -> Result<usize>`: Add or update publication dates in source files.
- `slugify_heading(heading) -> String`: Produce heading fragments aligned with frontend slugging expectations.

### Linking and Graph

- `resolve_links(index) -> LinkGraph`: Resolve exact filename wikilinks and calculate forward/backlinks.
- `LinkGraph::to_graph_json(index) -> GraphJson`: Emit normalized graph nodes and edges.

### Transformation

- `transform_content(index, post_idx) -> String`: Transform one post without returning copied asset paths.
- `transform_content_with_assets(index, post_idx, assets_dir) -> (String, Vec<PathBuf>)`: Transform one post and materialize assets.
- `extract_heading_section(content, heading) -> Option<String>`: Resolve heading transclusion content.

### Derived Artifacts

- `build_search_index(index) -> SearchIndex`
- `build_previews(index) -> serde_json::Value`
- `compute_related(index, graph, limit) -> Vec<Vec<String>>`
- `build_nav_tree(index, graph) -> NavTree`
- `write_output(index, graph, output_dir) -> Result<()>`

### Diagram Rendering

- `render_d2(...)`, `render_d2_bytes(...)`
- `render_mermaid(source, theme) -> Result<String>`
- `render_typst(source) -> Result<String>`

## Data Models

### PostMeta

- **Fields**: Slug, title, tags, dates, backlinks, forward links, hub flags, hub parent, description, reading time, word count, and related posts.
- **Relationships**: Links to other posts by slug and optional hub parent.
- **Validation**: Rust derives most values from filename/frontmatter. Duplicate filenames and slug collisions are not hard failures.
- **Contract Drift**: Rust emits `created` while TypeScript omits it; Rust emits `related_posts` while TypeScript makes it optional.

### GraphData

- **Fields**: Node list and slug-to-slug edge list.
- **Relationships**: Nodes reference posts; edges are normalized for output even though frontend naming describes directed edges.
- **Validation**: Link resolution is exact and case-sensitive.

### SearchIndex

- **Fields**: Documents and token-to-hit inverted index.
- **Relationships**: Hits refer to documents by integer index.
- **Validation**: Build-time text uses Lindera; browser query tokenization uses whitespace, producing a Korean morphology mismatch.

### NavTreeData

- **Fields**: Recursive roots and flat orphans.
- **Relationships**: Children combine hub-parent and forward-link semantics.
- **Validation**: No explicit cycle or multi-parent rejection.

### Preview Entry

- **Fields**: Title, tag list, summary.
- **Relationships**: Keyed by post slug.
- **Validation**: Summary is derived from stripped Markdown and first-sentence heuristics.

### GeoCache and SolarCache

- **Fields**: Coordinates or sunrise/sunset timestamps plus cache timestamps.
- **Relationships**: Stored in browser local storage.
- **Validation**: Failures fall back to fixed local times.

## Current Professional-Profile Contract

- **Homepage source**: External Vault `Passion Project.md`.
- **Rendered shape**: Heading plus unordered list of ordinary external anchors.
- **Local route contract**: None.
- **Structured résumé schema**: None.
- **Structured project schema**: None.
- **Print/download contract**: None.
- **Error or fallback behavior**: Browser-native external navigation only.
