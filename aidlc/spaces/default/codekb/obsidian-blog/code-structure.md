## Site Tooling (`site/scripts/`)

- `local-server.mjs` — production static server (no dependencies).
- `crossunit/link-sweep.mjs` — static internal-link check over `dist/`; `crossunit/ensure-fixture-content.mjs` — writes a fixture homepage artifact when absent.
- `hig/build-and-serve.mjs` — fixture preprocess + build + serve on 127.0.0.1:4329 for HIG Playwright checks.
- `profile/` — the profile command router (`cli.mjs`), Astro integration, font materializer, verification provider, PDF renderer/inspector/viewer, release store and coordinator, process custody and retry helpers, PBT runner, asset budget (inline-script baselines), accessibility review contract, homepage fixture content.

## Code Patterns

- **Fail closed with coded diagnostics**: Rust `PublicationDiagnostic` sorted by path then code, printed as `CODE path: detail`; TS throws `HPnnn path: detail`; profile code returns `ValidationResult` (`{ ok: true, value } | { ok: false, issues }`) and throws typed errors at boundaries.
- **Immutability**: `Object.freeze` throughout navigation, appearance and profile models; Rust data passed by reference with explicit clones into filtered views.
- **Shared regexes**: every Obsidian regex is a `LazyLock` in `syntax.rs` (local regexes in `transform.rs`, `hub_dates.rs`, `d2.rs`, `mermaid.rs` are module-private).
- **Fence awareness**: `transform_outside_fences` wraps every line transform; the site's slot counter is fence-aware too.
- **Module-level caches** in `data.ts` and `production-profile.ts` for SSG builds.
- **Requirement-cited comments**: comments explain why and cite IDs (BR-U2-*, FR*, NFR*, R-*, LC-U3-*).
- **Korean UI strings** inline in components; English identifiers.
- **Naming**: Rust `snake_case`; TS `camelCase` functions, `PascalCase` components/types, `UPPER_SNAKE_CASE` constants; kebab-case `.mjs`, CSS files and classes; tests `*_test.rs` or topic-named, `*.test.ts`, `*.pbt.test.ts`, `*.spec.ts`.

## Testing Layout

- `preprocessor/tests/`: `scanner_test`, `linker_test`, `transform_test`, `image_embed_test`, `block_ref_test`, `heading_ref_test`, `nav_tree_test`, `output_test`, `preview_test`, `search_test`, `d2_test`, `typst_test`, `publication_catalog`, `publication_output`, `publication_transform`, `pbt_framework_smoke`; `common/mod.rs` builds synthetic indexes.
- `site/tests/unit/`: 36 Vitest files (rendering, homepage composition, HIG tokens and built HTML/assets, search, appearance, profile domain and tooling, résumé release, site identity, graph view); `support/astro-build.ts` serializes isolated Astro builds through a lock directory.
- `site/tests/pbt/`: `u1/` profile properties (+ `arbitraries/`, `mutations.ts`, `setup.ts`), `u2/homepage-composition.pbt.test.ts`, `framework-selection.pbt.test.ts`.
- `site/tests/e2e/`: `hig-*.spec.ts` (7), `profile-*.spec.ts` (7), `portfolio-*.spec.ts` (2), `homepage.spec.ts`, `crossunit.spec.ts`; `support/` (environment, evidence, global setup/teardown, HIG route table, matrix, profile page helpers).

## 금번 집중 스캔에서 심독한 배포·검증 영역

아래는 스냅샷 고정 경로만 심독한 결과이며, 컴포넌트별 상세 책임은 `component-inventory.md`에 한 번만 기록했다.

| 경로 | 분류 | 심독 범위 |
|---|---|---|
| `Jenkinsfile` | Configuration (CI) | 125줄 전체. Verify/Preprocess/Build Site/Deploy 스테이지와 `RUN_DEPLOY` 파라미터 확인. |
| `Justfile` | Configuration (local orchestration) | 56줄 전체. `deploy`, `deploy-preprocess`, `crossunit` 레시피 확인. |
| `site/scripts/publish-dist.sh` | Utility (deploy) | 44줄 전체. bash, `set -eu`, 2-copy 게시와 리다이렉트 테이블의 원자적 교체. |
| `site/scripts/crossunit/link-sweep.mjs` | Utility (verification) | 167줄 전체. `sweep`/`loadKnownBroken` export, coded error `LINK001`. |
| `site/scripts/crossunit/ensure-fixture-content.mjs` | Utility (fixture) | 9줄 전체. `ensureE2eFixtureContent()` 위임. |
| `site/scripts/crossunit/known-broken-links.json` | Test fixture data | 7줄 전체. 의도적으로 깨진 이미지 1건 선언. |
| `site/scripts/hig/build-and-serve.mjs` | Tooling (harness) | 85줄 전체. 픽스처 전처리→빌드→4329포트 서버. |
| `site/package.json` | Configuration (npm) | 77줄 전체. 닫힌 명령 집합, pinned 버전, review subject 지위. |

`site/scripts/sync-public-assets.mjs`와 `site/scripts/redirect-table.mjs`(`.d.mts` 포함)는 폴더 목록으로 존재만 확인했고 내용은 읽지 않았다(스냅샷 범위 밖). 리다이렉트 테이블의 서버측 소비 경로도 미검증이다.
