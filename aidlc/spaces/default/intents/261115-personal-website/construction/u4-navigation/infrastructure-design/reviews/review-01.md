### Summary

The pipeline description is an accurate picture of the existing nightly job in most rows, but three release-path gaps make it unsafe to build U4 from: the documented pre-merge gate omits the type and format checks the team requires for UI work and that nothing else runs, U4's invalidation of the manual 16-state accessibility review (and the resulting closed `npm run test:e2e`) appears nowhere in the release path, and the Build Site row claims to grade the build-time budget that the Jenkins stage never measures. The deployment, monitoring and service-mapping rows also need accuracy corrections (which Playwright project runs which check, the non-atomic in-place deploy, the missing chrome.css budget row, the `--pages` input of the publishing step).
